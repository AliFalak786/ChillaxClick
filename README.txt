CHILLAX CLEAN URL VERSION
===========================

This package changes the site from hash/query navigation to real directory URLs.

IMPORTANT:
Upload the CONTENTS of this folder to the ROOT of your GitHub Pages repository.
Do not upload the outer folder itself.

Main URLs:
https://chillax.click/
https://chillax.click/ai-tools/
https://chillax.click/free-tools/
https://chillax.click/categories/
https://chillax.click/blog/
https://chillax.click/about/
https://chillax.click/contact/
https://chillax.click/privacy-policy/
https://chillax.click/terms/
https://chillax.click/cookie-policy/
https://chillax.click/disclaimer/
https://chillax.click/editorial-policy/

Also included:
- robots.txt
- sitemap.xml
- dashboard, premium, category and blog article clean routes

After uploading:
1. Open each main URL in Chrome and make sure it loads.
2. Open https://chillax.click/sitemap.xml
3. In Google Search Console, submit sitemap.xml.
4. Use URL Inspection for the main pages and request indexing.

Note:
A favicon.png file is not included because it was not present in the supplied HTML. Put your favicon.png in the repository root if you already have one.
